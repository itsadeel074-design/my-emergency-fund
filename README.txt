MY EMERGENCY FUND — Android-friendly savings tracker

Included:
- Daily Rs. 700 save button
- Rs. 130,000 target and progress bar
- Custom amount entries
- Monthly total, saving days, estimated target date
- Recent activity, undo today's latest entry, reset history
- Local-device storage and basic offline caching

To use on Android:
1. Upload the contents of this folder to an HTTPS static host (for example, GitHub Pages).
2. Open the hosted site in Chrome on your Android phone.
3. Use Chrome menu > Install app / Add to Home screen.
4. Your savings entries are stored in that browser on that device.

Important:
This is an installable Progressive Web App (PWA), not a compiled APK. The project does not send your savings data to a server. Clearing browser data may erase the tracker history, so keep a separate backup if the records are important.
